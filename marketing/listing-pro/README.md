# The Pro sentence of the listing, for the first Apple release after 1.82

Tailscode no longer shows a supporter heart, a tip jar or any request for support: Pro is told as what the buyer gets.
The live 1.82 listing still ends its Pro sentence on "a supporter heart", and a live version's text cannot change, so
the corrected `description` of each of the fourteen languages 1.82 ships waits here, per train (`version.ios`,
`version.macos`): 1.82's own text with that sentence ending on the delegate board.

When the next version's folders are written, take `description` from these files instead of from 1.82's. The Swedish,
Danish, Norwegian and Finnish listing in `marketing/listing-nordic/` already carries the same wording.
